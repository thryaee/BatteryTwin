# ML Training Data

## ⚠️ Important Notice

All data in this directory is **synthetically generated** using physics-informed
battery models. It is **not** derived from real battery measurements.

### What this means

| What it IS | What it is NOT |
|---|---|
| Realistic approximation of Li-ion behaviour | Measured laboratory data |
| Sufficient for demo / proof-of-concept | Validated against real cells |
| Good for testing the ML pipeline end-to-end | Production-grade predictions |

### When to replace with real data

Once you have real ESP32 hardware collecting data, replace the CSV files here
with logged readings. The ML pipeline (`trainer.py`) will automatically retrain
on whatever data it finds.

Public datasets you can use for improved models:
- **NASA Battery Dataset** – https://data.nasa.gov/dataset/Li-ion-Battery-Aging-Datasets
- **CALCE Battery Dataset** – https://calce.umd.edu/battery-data
- **Oxford Battery Degradation Dataset** – https://ora.ox.ac.uk/objects/uuid:03ba4b01-cfed-46d3-9b1a-7d4a7bdf6fac

### Files generated by `synthetic_data.py`

| File | Description |
|---|---|
| `synthetic_battery_cycles.csv` | One row per cycle: voltage, current, temp, SOC, SOH, RUL, degradation |
| `synthetic_timeseries.csv` | Second-by-second readings for 50 simulated batteries |

### Columns

```
cycle_number, voltage_v, current_a, temperature_c, soc_percent,
soh_percent, rul_cycles, degradation_rate, c_rate, capacity_mah,
internal_resistance_ohm, data_source
```
